# Project NullSpace

A 2D top-down space shooter built in Godot.

## Project layout

- `scenes/` — Godot scenes (`.tscn`)
- `scripts/` — scene scripts and `autoload/` singletons
- `assets/` — original images and fonts, organized by purpose
- `resources/ui/` — reusable Godot UI resources (`.tres`)
- `data/waves/` — wave definitions
- `addons/` — editor plugins
- `docs/` — project notes and legacy configuration

Open the root `project.godot` file in Godot. The `.godot/` import/cache folder is generated by the editor and is not stored in Git.

This structure-only refactor intentionally preserves existing GDScript gameplay logic and original asset filenames. Assets will be reimported when first opened in Godot. The incomplete terminal add-on was removed; only the Git integration add-on remains.
